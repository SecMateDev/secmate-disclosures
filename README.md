This repository is the public, searchable index of vulnerabilities discovered by the SecMate research team using [SecMate](https://secmate.dev), our code security analysis platform.

The findings affect third-party open-source projects and vendor software. Each entry links to the complete disclosure on [secmate.dev](https://secmate.dev/disclosures) and, when available, its associated article on the [SecMate research blog](https://blog.secmate.dev).

## Methodology

SecMate analyzes repositories using program analysis, Code Property Graphs, data-flow tracking, and program slicing. These tools isolate the code and execution paths relevant to each candidate finding. Language models examine that bounded evidence, and SecMate researchers validate the result against the source code before disclosure.

The research documented here in 2025 and 2026 primarily used the open-weight [`gpt-oss-20b`](https://developers.openai.com/api/docs/models/gpt-oss-20b) and [`gpt-oss-120b`](https://developers.openai.com/api/docs/models/gpt-oss-120b) models. Changing models requires integration work and evaluation within the complete analysis workflow.
