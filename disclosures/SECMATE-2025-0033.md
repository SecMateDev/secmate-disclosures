# CVE-2025-68656 — USB Host HID Descriptor Use-After-Free

Espressif's esp-usb HID host component before version 1.1.0 contains a use-after-free when processing oversized, attacker-controlled report descriptor lengths. The descriptor request path reallocates a transfer object but continues using a stale pointer, allowing a malicious USB HID device to corrupt freed heap memory and potentially execute code on the host.
