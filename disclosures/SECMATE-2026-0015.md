# SECMATE-2026-0015 — Unsafe Callsign Handling in Sagetech XP ADS-B Driver

ArduPilot's Sagetech XP ADS-B backend handled callsign data using an incorrect destination within the vehicle record. Unexpected receiver data could corrupt related state and cause incorrect behavior or instability. The affected parser is reached through a dedicated sensor serial link, and no remote radio-to-parser attack path was established.
