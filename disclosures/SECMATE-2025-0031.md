# CVE-2026-1679 — eswifi Socket Send Buffer Overflow via Unbounded Payload

The eswifi socket offload driver in Zephyr RTOS contains a buffer overflow vulnerability where user-provided payloads are copied into a fixed buffer without bounds checking. Oversized sends via eswifi_socket_send corrupt kernel memory, potentially leading to code execution or denial of service.
