# CVE-2026-28520 — WiFiMulti Single-Byte Heap Overflow in addAP

A single-byte (off-by-one) heap overflow vulnerability exists in the WiFiMulti addAP function of arduino-TuyaOpen versions prior to v1.2.1. An attacker can exploit this vulnerability when a victim connects to a malicious AP hotspot, potentially enabling overflow-based code execution on the device firmware.
