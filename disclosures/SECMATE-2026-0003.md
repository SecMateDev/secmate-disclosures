# CVE-2026-28522 — WiFiUDP Null Pointer Dereference via Malicious Packets

A null pointer dereference vulnerability exists in the WiFiUDP component of arduino-TuyaOpen versions prior to v1.2.1. An attacker on the same local area network (LAN) can continuously send a large number of malicious packets to a device with the WiFiUDP service enabled, causing memory exhaustion and ultimately leading to denial of service.
