# CVE-2026-42806 — BME690 Gas Index Out-of-Bounds Read

BME690 SensorAPI v1.0.3 and earlier does not validate the sensor-controlled gas_index before using it to index a 30-byte stack buffer. Values from 10 to 15 read beyond the valid heater table, which can corrupt measurement data and expose adjacent stack memory through the public gas_wait field.
