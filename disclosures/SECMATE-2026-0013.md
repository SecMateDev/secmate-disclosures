# CVE-2026-27816 — ISO15118 Energy Transfer Modes Overflow Corrupts EVSE State

A buffer overflow vulnerability exists in EVerest's ISO15118 charger implementation. The system copies variable-length lists into a fixed 6-element array without bounds validation. When schema validation is disabled (default), oversized MQTT payloads can trigger out-of-bounds writes, corrupting adjacent EVSE state or crashing the process.
