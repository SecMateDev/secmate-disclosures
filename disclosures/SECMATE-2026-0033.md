# CVE-2026-42805 — BHI385 Debug FIFO Stack Buffer Overflow

BHI385 SensorAPI versions from 1.1.0 to before 2.1.0 read a message length from a sensor FIFO event and copy that many bytes into a fixed 17-byte stack buffer in bhi385_parse_debug_message() without enforcing the buffer limit. A malicious sensor or bus participant can corrupt adjacent stack data, crash the host, or potentially execute arbitrary code.
