# CVE-2025-68622 — Stack Buffer Overflow in UVC Descriptor Printing

Espressif's esp-usb UVC host component before version 2.4.0 contains a stack buffer overflow in configuration descriptor parsing when verbose descriptor printing is enabled. A malicious USB Video Class device can provide an oversized descriptor that corrupts stack memory, causing denial of service and potentially altering control flow.
