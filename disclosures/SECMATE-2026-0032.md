# CVE-2026-42804 — BHI360 Debug FIFO Stack Buffer Overflow

Affected BHI360 SensorAPI revisions up to and including commit d6b200416a trust a sensor-controlled debug-frame length in bhi360_parse_debug_message() and copy it into a fixed 17-byte stack buffer without bounds checking. A malicious sensor, counterfeit module, or I2C/SPI bus participant can corrupt stack memory on the host MCU or SoC, causing denial of service and potentially arbitrary code execution.
