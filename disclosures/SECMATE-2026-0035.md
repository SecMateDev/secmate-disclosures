# CVE-2026-42807 — COINES PC Bridge Heap Buffer Overflow

COINES SDK versions 2.10 through 2.12.2 trust a packet length supplied by a connected USB or BLE device before copying the response into a fixed-size host queue slot. A malicious or compromised peripheral can trigger an out-of-bounds heap write, causing a process crash or potentially arbitrary code execution on the developer workstation.
