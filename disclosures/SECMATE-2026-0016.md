# SECMATE-2026-0016 — Out-of-Bounds Write in uAvionix GDL90 Message Parsing

ArduPilot's uAvionix GDL90 ADS-B backend could write beyond its internal message buffer while processing malformed or corrupted serial input, potentially crashing the flight stack or corrupting state. The affected parser is connected to a dedicated ADS-B sensor serial link, and no remote radio-to-parser attack path was established.
