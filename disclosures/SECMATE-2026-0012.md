# CVE-2026-27815 — ISO15118 Session Setup Payment Options Overflow Corrupts EVSE State

The EVerest core's ISO15118 charger implementation copies variable-length payment option lists into a fixed-size 2-element array without bounds validation. Oversized MQTT payloads can trigger out-of-bounds writes that corrupt adjacent state or crash the process.
