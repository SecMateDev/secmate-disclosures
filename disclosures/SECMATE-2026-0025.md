# SECMATE-2026-0025 — USB Host Audio IN Interface Count Out-of-Bounds Write

STM32Cube USB Host Library 3.5.4 and earlier records AudioStreaming IN interfaces in a fixed five-entry array without bounding the alt_settings index. A malicious USB audio device can expose more than five matching interfaces during enumeration and cause an out-of-bounds write, memory corruption, or a host crash. ST fixed the issue in USB Host Library 3.5.5.
