# CVE-2026-40257 — SHA-3 Accelerated Finalize Heap Overflow

OP-TEE versions 3.21.0 through 4.10 contain an off-by-one error in the ARM Crypto Extensions accelerated SHA-3 implementation. Finalizing a digest after processing an exact block can underflow a padding length and trigger a massive heap overwrite, reliably crashing the TEE kernel. The issue affects builds with SHA-3 Crypto Extensions enabled and is fixed in version 4.11.0.
