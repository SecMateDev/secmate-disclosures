# CVE-2026-0849 — ATAES132A Response Length Allows Stack Buffer Overflow

A stack buffer overflow vulnerability exists in Zephyr's ATAES132A crypto driver. A malformed device response with an oversized length field can overflow a 52-byte stack buffer in ataes132a_send_command. An attacker controlling the device or I2C bus could trigger this vulnerability to corrupt kernel memory.
