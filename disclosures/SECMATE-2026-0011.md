# CVE-2026-27828 — ISO15118 Session Setup Use-After-Free Crashes EVSE Process

A use-after-free vulnerability exists in EVerest's ISO15118 charger implementation. When initialization fails, the v2g_ctx object is freed but command handlers remain active. An attacker with MQTT access can trigger a session_setup command that dereferences the freed memory, causing process termination.
